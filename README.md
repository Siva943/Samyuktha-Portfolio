# Dr. M. Samyuktha — Academic Portfolio

A responsive, single-page academic portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `samyuktha_portfolio` folder.
3. Double-click `index.html`, or open the folder in VS Code and use the Live Server extension.

## Included
- Responsive layout for desktop, tablet and mobile
- Profile photo cropped from the supplied debate-competition image
- About, experience, education, research/publications, workshops and contact sections
- Mobile navigation

## Personal information and accuracy
The portfolio uses the supplied resume as its content source. Personal details such as date of birth, marital status, family details and residential address have been omitted for privacy. Employment dates, journal article titles, and publication URLs were not provided, so they have not been invented. The profile photo is cropped from the supplied group photograph; a dedicated portrait would produce an even stronger result.

## Customise
- Replace `assets/dr-samyuktha-profile.jpg` with a high-resolution portrait if available.
- Edit `index.html` to update profile text and contact details.
- Edit `style.css` to change colours and layout.
